3. If you found any bugs and how you solved them.
Simple English
Initially, I used a while loop and a try-catch block to check the number of rounds entered by the user. However, I placed the first scanner.nextInt() outside the try-catch block.

Because of this, the program crashed when the user entered text instead of a number. The error was not handled.

I used breakpoints to debug the code and understand where the problem occurred.

With the help of AI, I understood the problem and changed the code. I initialized numberOfRounds to 0 and moved the input statement inside the try-catch block within the while loop.

By setting the initial value to 0, the loop runs at least once. The condition numberOfRounds <= 0 makes sure that the user is asked again until they enter a positive number. The try-catch block handles text inputs and prevents the program from crashing.

After fixing the problem, I tested all input fields with both valid and invalid values. This helped me make sure that users could enter the correct values again without the program stopping unexpectedly.
Enkel svenska
I början använde jag en while-loop och ett try-catch-block för att kontrollera hur många rundor användaren ville spela. Men jag placerade den första scanner.nextInt() utanför try-catch-blocket.

Därför kraschade programmet när användaren skrev text i stället för ett nummer. Felet hanterades inte av programmet.

Jag använde breakpoints för att felsöka koden och förstå var problemet uppstod.

Med hjälp av AI förstod jag problemet och ändrade koden. Jag satte startvärdet för numberOfRounds till 0 och flyttade inmatningen inuti try-catch-blocket i while-loopen.

När startvärdet är 0 körs loopen minst en gång. Villkoret numberOfRounds <= 0 gör att användaren får försöka igen tills ett positivt tal anges. try-catch-blocket hanterar textinmatningar och förhindrar att programmet kraschar.

Efter ändringen testade jag alla inmatningsfält med både giltiga och ogiltiga värden. På så sätt kunde jag kontrollera att användaren kunde skriva in rätt värde igen utan att programmet avslutades.
